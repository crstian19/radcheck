| Path | Source | Licence |

| `data/processed/` | Output of the error injector | Inherits CC BY-NC-SA 4.0 |
| `data/radiologist/` | Synthetic reports written by the collaborating radiologist | To be agreed (see docs/data.md) |

Never place real patient reports here, de-identified or not.
